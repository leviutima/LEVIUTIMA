## Projects

**[Cave Mode](https://github.com/leviutima)**
Life management app covering finances, diet, goals and health. Built solo, front to back. Expo and React Native on the front, NestJS with hexagonal architecture, PostgreSQL and Prisma on the back. Auth over OAuth2 with PKCE, built as the first vertical instead of bolted on later.

**[create-fsd-app](https://github.com/leviutima/create-fsd-app)**
CLI that scaffolds Vite, Next.js and Expo projects in Feature-Sliced Design, with architecture linting so the structure holds as the codebase grows. Built because most front-end projects do not fail on syntax. They fail on structure nobody agreed on.

**[spec-trace](https://github.com/leviutima/spec-trace)**
CLI that checks whether tests actually prove the requirements they claim to cover. Flags uncovered requirements, orphan tests, and assertions too weak to fail. Deterministic, no LLM involved.
